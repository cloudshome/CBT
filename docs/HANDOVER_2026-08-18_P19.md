## What this is

One supported layout and operator CLI for an always-on SKY Hub. The desk
is still paper-first and advisory. **No package contains an exchange-order
path.** Packaging is not evidence of profitability.

## Layout

| Path | Role |
|---|---|
| `/opt/sky` | immutable application tree |
| `/etc/sky/sky.env` | private config (0640) |
| `/var/lib/sky` | SQLite, Parquet store, backups |
| journald | logs (`sky logs`) |

Tests use `SKY_HUB_PREFIX` so the same code never touches a live `/opt`.

## Operator CLI

```bash
python main.py hub setup --mode local|remote
python main.py hub status
python main.py hub doctor
python main.py hub backup
python main.py hub restore --archive /var/lib/sky/backups/sky-backup-….tar.gz --overwrite
python main.py hub logs --unit sky-dashboard.service
python main.py hub uninstall          # keeps data
python main.py hub uninstall --purge  # deletes data — explicit
```

Debian postinst installs `/usr/bin/sky` which forwards to `main.py hub`.

## Hardened units

`ops/systemd/sky-{dashboard,paper,scan,backup}.service` plus scan/backup
timers. Dashboard binds **127.0.0.1:8050**. TLS lives in `ops/proxy/`
(Caddy + nginx examples). Private `/api/*` is `Cache-Control: no-store`.

## Backup contract

- SQLite online backup API (not a file copy of a live DB).
- Env tokens redacted (`TELEGRAM_BOT_TOKEN`, `SKY_SECRET_KEY`, LLM keys).
- Archive mode `0600`; world-readable archives are refused.
- Default retention 14 days (`sky-backup.timer` at 03:17 UTC).

## Honest limits

- This checkout **does not ship a signed Debian repository**. 
  `packaging/build_deb.sh` produces an **unsigned** `.deb` + SHA-256 when
  `dpkg-deb` is present. Signing credentials never live in the repo (P22).
- No clean Ubuntu VM was provisioned in this sandbox, so install/reboot/
  restore-onto-a-second-VM was **not** executed. Mechanics are proven by
  `tests/test_hub.py` under a fake FHS prefix.
- Owner password creation stays in P18.1 (`web.auth`) — `hub setup`
  records mode + storage, it does not invent a second user table.
- Legacy `cryptobrain-*.service` files remain as compatibility aliases.

## Safety

No threshold moved. No live order module. Uninstall without `--purge`
keeps `/var/lib/sky` and `/etc/sky`.
