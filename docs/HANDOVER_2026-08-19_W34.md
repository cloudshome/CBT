## What this is

The last HANDOVER Priority-3 item left standing after W3 (v2.41.0): **practice
scoring the trader's own read against the desk's**. The decision inherited
from the W3 handover was "form, not before/after screenshots" — a form is
deterministically scorable, a screenshot is not.

The flow the trader lives:

1. Look at the 📊 Chart tab chart. **Do not open the Signal desk yet.**
2. Commit YOUR read in the ✍ PRACTICE card: bias (bullish / bearish /
   neutral), final call (buy / sell / no-trade), and optionally the full
   ladder (entry / stop / target), confidence and a note.
3. Submit → the server computes the desk's read **at that moment**
   (`save=False` — a practice read never enters the scans queue or the
   pending-review pipe), freezes both reads side by side, scores the
   agreement, and remembers the attempt.
4. The 🗓 Review tab PRACTICE CALIBRATION card mirrors the window: agreement
   rates, component means, the weakest link, one deterministic coaching
   takeaway, recent attempts.

## Delivered

### `brain/practice.py` (one computation, many surfaces — invariant #10)

- `desk_read_from_payload(payload, symbol, tf)` — freezes action / bias
  (from the engine's weighted bull-vs-bear condition scores, neutral on tie,
  `None` honestly when scores are absent) / ladder (entry, stop, target, R:R,
  plan type, confidence) / regime / ATR / price / signal_id. Never raises;
  `available: False` on absent payloads.
- `validate_user_read(body)` — **fail-closed**: closed vocabularies for bias
  and decision, cleaned symbol, closed timeframe set, positive finite
  numbers, confidence 0–100, note capped at 500 chars. A *half-plan*
  (entry without a stop, target without an entry) is **rejected, not
  scored** — the message says why.
- `score_attempt(user, desk)` — deterministic, every component visible:
  - **directional bias** /35: exact 35, one side neutral (partial credit,
    honest: "the most honest non-answer") 15, opposite 0;
  - **final call** /35: exact 35; you passed while the desk had a plan
    = 15 (a *miss* — safe but unearned); you traded against a desk NO TRADE
    or on the opposite side = 0 ("overruled the filter");
  - **the ladder** /30, only when both sides have one: entry proximity vs
    the desk's ATR (0.5×/1×/2× → 10/7/4), stop on the right side of your own
    entry 10, your implied R:R vs the desk's unchanged **≥1.5R floor** 10/5/0.
  - No ladder (either side) → components renorm over 70 so a call-only read
    can still reach 100. Grade A/B/C/D/E on the same bands as the weekly
    grade (85/70/50/30). The desk's own 1.5R floor is **quoted, never moved**.
- `practice_scorecard(db, days=30)` — windowed n, bias/call agreement rates,
  component means, avg/best/worst, grade tallies, weakest link →
  deterministic coaching text, recent attempts newest-first, honest empty
  state, and the standing disclaimer: *agreement with the desk is study, not
  evidence — the desk proves itself only under the unchanged graduation bar.*
  Perfect agreement names **no** weakest link instead of inventing one.

### `practice_attempts` table + double-submit guard

Per-attempt store (ts, symbol, timeframe, full user/desk/score JSON).
An identical read inside 2 minutes returns the original attempt — history is
never inflated by double-taps or retries. **Coaching memory ONLY**: no
live-book, risk-gate, calibration or graduation surface joins this table —
pinned by `tests/test_practice.py::
test_practice_rows_never_reach_the_live_book_or_graduation`
(weekly review + `paper_progress()` + `live_book_rows()` byte-identical
before/after attempts).

### Surfaces

- `python main.py practice [--days N] [--json]` — boxed calibration report.
- `GET /api/practice` — the scorecard; audited `POST /api/practice` —
  validation **first** (400, fail-closed, nothing recorded), then the engine
  read (502 + *nothing recorded* when unavailable — an unscorable attempt
  would corrupt calibration), then the audited save + reveal.
- Dashboard 📊 Chart tab ✍ PRACTICE card (form + reveal: desk pill vs your
  call, component rows with points, disclaimer riding with every reveal) and
  🗓 Review tab PRACTICE CALIBRATION card.
- Root MCP `practice_scorecard` (server **1.13.0**) + SDK
  `cryptobrain_practice`; Command Center "Practice calibration" card.
  Both read-only, behind the same permission map.

## Honesty section (per §0a)

- **What this measures and what it does not.** It measures agreement with
  *this desk, at that moment*. It is not evidence the desk is right — the
  desk itself is still proving that under the unchanged
  +0.50R / 55% / PF 1.5 / compliance ≥90% bar. The UI and CLI say this on
  every reveal and scorecard; do not remove the disclaimer.
- **Honesty depends on the trader.** They can always peek at the Signal desk
  before submitting — the app cannot prove they didn't. Like a flash-card,
  cheating only corrupts their own mirror; the audit log records every
  commit. This is flagged in the cards' copy.
- **Fresh desk read per submit.** The endpoint calls
  `compute_payload(save=False, use_cache=True)` — the cache may be up to the
  scan TTL old; the frozen `signal_id` rides with each attempt so drift is
  auditable.
- **No browser in this sandbox** (same as W3): JS was proven through the
  node/jsdom harness + Flask test client + the pre-existing served-JS
  validity tests. `DEMO_MODE` works offline (sample payload), so the full
  round trip is exercised in CI.
- **Fixed a CI-caught regression along the way:** the TODO.md rewrite in
  v2.41.0 dropped the pinned phrase "next implementation is P22…"
  (`test_product_surfaces_state_installers_are_planned_not_shipped` failed on
  PR #62's "Offline test suite"). Restored the exact pinned phrase and
  one-form reprimanded in this file so the next session sees it.

## Not built (handoff, do not pretend otherwise)

- **W3.5 multi-chart views** — the W2 remainder (side-by-side symbol/TF
  charts). Untouched here; the chart workspace is unchanged apart from the
  practice card.
- **Replay-integrated practice** — scoring a read against *future* bars in
  replay mode (the strongest form of practice: your read, then the tape
  plays out). Needs a forward window definition + outcome scoring; a good
  candidate for the session after W3.5.
- **Outcome-linked calibration** — joining a committed practice read to the
  later paper-trade outcome of the same signal. Deliberately not done: it
  must wait until the canonical book proves the desk's reads are worth
  agreeing with.
- **P22 trusted-host signing drills** — need real Windows/Android/Ubuntu
  signers; catalog only (`python main.py release drills`).
