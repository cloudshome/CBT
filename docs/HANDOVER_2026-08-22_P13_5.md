## What shipped

P13.5 closes the Monte-Carlo item from the P13 edge-validation spec
(`docs/P13_EDGE_VALIDATION_SPEC.md` §3.5). The edge verdict now resamples the
decisive-window (OOS + recent) net R series and applies a **stability floor**
as a confirm condition: the 5th-percentile bootstrap net expectancy must be
> 0 or the edge is rejected as NO EDGE.

A book that is net-positive in the mean but has a fat left tail — one bad
streak from negative — no longer gets EDGE_CONFIRMED. The MC floor can only
tighten the verdict, never loosen it.

### Code

- **`engine/edge_validation.py`**
  - `monte_carlo_decisive(plans, samples, risk_pct, ruin_threshold_pct, seed)`
    — bootstrap resampling of the decisive-window decided plans' net R.
  - `edge_verdict()` accepts `monte` (optional dict) and `monte_floor` (bool,
    default True). When MC data is available and the floor is on, p5
    expectancy ≤ 0 → NO EDGE.
  - `edge_validate_report()` accepts `monte`, `monte_samples`,
    `monte_risk_pct`, `monte_seed`.
  - `format_edge_verdict()` prints the full MC table when available.
- **`main.py`** — `edge-validate` gains `--monte`, `--monte-samples`,
  `--monte-risk-pct`, `--monte-seed`.

### CLI usage

```bash
# Basic verdict (unchanged from P13.3)
python main.py edge-validate --source store --tf 15m --bars 2000

# With Monte-Carlo stability floor (P13.5)
python main.py edge-validate --source store --tf 15m --bars 2000 --monte

# With custom MC parameters
python main.py edge-validate --source store --tf 15m --bars 2000 \
    --monte --monte-samples 5000 --monte-risk-pct 0.5 --monte-seed 42

# JSON output (MC block is in `monte` key)
python main.py edge-validate --source store --tf 15m --bars 2000 --monte --json
```

## Verdict rules (with MC floor)

1. Fewer than `min_decided` decided trades → **INSUFFICIENT_DATA**
2. Overall net expectancy ≤ 0 → **NO EDGE**
3. Positive net expectancy in < `positive_regime_frac` of well-sampled regimes
   → **NO EDGE** (unstable across regimes)
4. **(P13.5) MC p5 net expectancy ≤ 0 → NO EDGE** (unstable under resampling)
5. Otherwise **EDGE_CONFIRMED** (provisional if regime coverage is thin or
   MC unavailable)

## Honest boundaries

- `edge-validate --monte` is read-only — it never places an order, never
  moves a threshold, never unlocks micro-live.
- The MC floor is a confirm condition, not a gate-bypass — it can only
  reject, never approve.
- This checkout has no real data: MC mechanics are verified on synthetic
  series only; the real-data host must confirm.
- Default `--monte` off: the graduation gate and all pre-P13.5 invocations
  produce byte-identical results.
