# Handover — 2026-08-20 · v2.51.0 — T2: AI Copilot polish

**The Copilot finally reads like a desk, not a log.** In v2.49.0 (T1) the
drawer shipped with a fragile client-side section parser that never matched
the backend's answers, double-printed the raw text, and comma-joined the
answer list into one line. In v2.51.0 the backend defines the structure and
the grounding, and the frontend just renders it.

**No new trading capability.** Every change is advisory UI or additive
answer metadata. No threshold moved, no exchange-order path, no new
permission, no mutation.

## What shipped

### Backend (`brain/agent.py`)

- **`ask()` returns `sections` + `sources` on every intent.** `ask` is now
  a thin public wrapper: it calls the renamed `_ask_impl` (unchanged intent
  routers) and decorates the result via `_decorate_answer`. `sections` is a
  list of `{title, body}`; `sources` names the exact surface each number
  came from (`risk gate — brain.risk_gate.evaluate`, `open paper book —
  SignalDB.live_open_rows`, …) — honest grounding, never an invented
  citation. The plain `answer` list is untouched, so `python main.py agent
  ask`, MCP `cryptobrain_ask`, and every existing test read what they
  always read.
- **`market` splits into two sections** — `Market read` (asset/action/conf/
  entry/reason) and `Desk decision` (vetoes, or "no veto").
- **`exposure` carries measured evidence** — the canonical live-book count
  (P12.16 `live_open_rows`) is stated separately from planned exposure, and
  each carried plan type gets its calibrated expectancy + paper n +
  proven/unproven line. The whole block ships as a single `Open positions`
  section, with `live_open` and a trimmed `calibration` map in `data`.

### Frontend (served `web/app.py` script; `web/static/terminal_newjs.js` kept in sync)

- **`aiSend` fixed.** Joins list answers with newlines, renders the
  backend's `sections` when present, falls back to plain text otherwise,
  and appends a dashed **Sources** footer via `aiAppendSources`. The old
  regex parser and its `|| true` double-print are gone.
- **`aiPrepareTicket()`** — the new "Prepare ticket" quick action (global
  drawer + order-panel Copilot). Pre-fills side/type/entry/SL/TP from
  `window._skyPayload` (the desk plan) and switches to the Ticket tab.
  Advisory only: never confirms, never posts; on `NO TRADE` it toasts
  "the desk says stand aside".
- **Symbol/timeframe-aware** — `aiSend` now sends `symbol` + `tf`, so
  "Review this signal" / "Explain this chart" target the market on screen,
  not the server default.
- **CSS** — `.ai-msg.ai-sources` (dashed border, muted) for the footer.

## Honest boundaries (unchanged)

- The Copilot is advisory. It never approves, never confirms, never places
  or simulates an order.
- `context` is still client-supplied and the intent router still answers
  from the DB/engine (it ignores the free-text context string); the
  meaningful context (open positions, measured expectancy, selected
  symbol/timeframe) now flows through first-class fields, not prose.
- `answer` is still a list of lines; `sections`/`sources` are additive.
- No real browser exists in this sandbox — the UI was proven with the node
  harness + Flask test client + `node --check` on the served script, not by
  a human looking at a screen.
