## Why this build exists

The ChatGPT "professional trading desk" talk (16 layers + the five-question
ladder) was mapped against the repo and turned out to describe SKY almost
exactly as it is. Four small deltas survived the filter:

1. **A/B/C key-level ranking** — the report listed levels but never ranked them.
2. **Five-question coach** — the coach taught, but not in the professional
   Observation → Interpretation → Opportunity → Decision → Action structure.
3. **Position-manager card at approval time** — the desk report already shipped
   a management plan, but it was never shown at the moment of commitment.
4. **No-martingale invariant** — true in code, never stated as a rule.

P13 ships all four.

## What shipped

### P13.1 — five-question coach (`brain/coach.py`)

- **`five_levels(payload, db=None)`** — answers the five questions in plain
  English. Built entirely from data the engine already produces:
  - **L1 OBSERVATION:** `_feature_plain()` snapshot lines.
  - **L2 INTERPRETATION:** trend-bias sequence, structure-event *meaning*
    (new `_EVENT_MEANING` map: BOS/CHOCH → what it implies), regime hint
    (ranging = fade extremes, trending = pullbacks with the trend), premium/
    discount meaning.
  - **L3 OPPORTUNITY:** top plan + confidence + IF/THEN condition, plus
    **`_setup_evidence()`** — the measured per-setup expectancy from the
    learning loop (`db.backtest_stats()`) when samples exist, and an honest
    "no graded samples yet — paper-trade it and let the calibrator learn"
    otherwise (n<10 → "too few to trust yet").
  - **L4 DECISION:** the desk decision (`payload["decision"]` → else
    intelligence → else signal), every `blocked_by` reason, and the
    "Score ≠ permission — confidence X% (floor ≥80%), R:R Y (≥1:1.5), risk
    Z%" line.
  - **L5 ACTION:** entry/stop/targets/R:R, position size, the
    `management_checklist()`, and **a ⚠️ "desk says NO TRADE — this plan is a
    watch-item only" warning** whenever the desk decision is NO TRADE but a
    plan exists. Closes the "L4 says no, L5 shows entries" teaching gap.
- **`management_checklist(plan=None)`** — HOLD / REDUCE / TRAIL / EXIT card
  for one plan; single source of truth shared with P13.3. Ends with the P13.4
  invariant line. No plan → "no active plan — the best trade is no trade."
- Wired into `python main.py coach` as "🎯 THE FIVE QUESTIONS" between mentor
  and personal feedback.

### P13.2 — A/B/C key-level ranking (`brain/trading_intelligence.py`)

- **`rank_key_levels(features, plan=None)`** — new `key_levels` section in the
  desk report (`intelligence`, `/api/scan`, MCP, dashboard card).
  - **A — liquidity & major structure:** sweep level, liquidity pools above/
    below, equal highs/lows, swing high/low.
  - **B — decision zones:** bullish/bearish order blocks, plan trigger, plan
    entry.
  - **C — reference levels:** FVGs, VWAP, POC, stop loss, take-profits.
  - Within a tier: sorted by `distance_pct` from price; capped at 6 per tier.
  - **No invented levels** — every entry comes from the feature snapshot or
    the plan. `price is None` → empty list (fail soft).

### P13.3 — approval-time position-manager card (`main.py cmd_approve`)

- Before `approve` commits, the CLI prints the HOLD/REDUCE/TRAIL/EXIT card for
  the exact stored plan (`_primary_plan(scan)`), including the immutable-risk
  line. Works with `--force` overrides too (the card prints before the
  override warning).

### P13.4 — no-martingale invariant (docs)

- **BLUEPRINT.md Golden Rule 6:** "Never average down — the risk budget is
  immutable… the only allowed accumulation is Step-4 *investment* DCA."
- **`brain/playbooks.py` module docstring:** states the invariant so no future
  session accidentally "improves" in an averaging-down path.
- Surfaced to the human in both P13.1 and P13.3 output.
