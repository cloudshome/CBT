# Handover — 2026-08-22 · v2.56.0 — P13.4: the O(N²) backtest walk is gone

**What shipped:** the backtest and simulator walks no longer recompute every
indicator from bar 0 at each step. Indicators are precomputed once over the
full series, and each bar is analyzed through the new windowed
`analyze_frame_at`. This is the "precompute + incremental structure" phase of
the P13.4 spec: **behaviour-identical, ≥3–10× faster** — measured **5.7× on
500 bars, 7.9× on 2000, ~200× on a 10k-bar walk** (est. 2h+ → ~40s).

**No new capability, no threshold moved, no exchange-order path.** The engine's
outputs are byte-identical; only the cost of producing them changed.

## Why it was O(N²)

`run_backtest` and `_walk_symbol` called `analyze_frame(df.iloc[:i+1])` at
every step, and `add_all_indicators` re-ran the entire suite (rolling/EWM
columns, the Supertrend recurrence, VWAP groupbys) over the growing prefix:
O(N²) row-work plus an O(N) Python loop per step inside Supertrend.

The detectors were already windowed — `analyze_structure` looks at
`tail(200)`, `find_rsi_divergence` at `tail(80)`, `classify_market_regime` at
`tail(15)` (with a `len < 20` guard) — and every window is prefix-consistent
(the slice always started at row 0), so precomputing the columns once and
slicing windows per bar is provably identical.

## What changed

### `engine/signal_engine.py` — `analyze_frame_at` (+ shared `_analyze_at`)

New entry point for the walk: `analyze_frame_at(ind, raw, i, ...)` analyzes
bar `i` from the precomputed indicator frame `ind = add_all_indicators(raw)`:

- structure: `raw.iloc[max(0, i-199):i+1]` (the 200-row tail)
- divergence: `ind.iloc[max(0, i-79):i+1]` (needs `close` + `rsi` + OHLC)
- snapshot: last two rows of `ind` + `frame_len=i+1` (so `event_age` is
  measured against the full walk prefix, not the 2-row slice)
- regime: `raw.iloc[max(0, i-19):i+1]` (20 rows satisfies the `len < 20`
  guard; the classifier still reads its `tail(15)`)

`analyze_frame` now delegates to the same `_analyze_at` with `i = len(df)-1`,
so live scans and the walk share one pipeline. Window sizes are pinned as
module constants (`STRUCTURE_LOOKBACK`, `DIVERGENCE_LOOKBACK`,
`REGIME_MIN_ROWS`) in lockstep with the detector defaults.

### `engine/features.py` — `build_snapshot(..., frame_len=None)`

Optional prefix length for `event_age`. When omitted, behaviour is exactly as
before (`len(df)`). Only caller is `signal_engine`.

### `engine/structure.py` — vectorized detectors (identical results)

- `detect_swings`, `detect_order_blocks`, `detect_fvgs`, `detect_liquidity`
  read numpy arrays instead of per-row pandas attribute access (the 120k
  `__getattr__` calls in the profile).
- "Any later bar reached the level" checks (FVG `filled`, OB `tested`/
  `broken`) are now one reversed `cummin`/`cummax` per frame instead of a
  tail scan per event.

### `data/costs.py` — cached funding lookup

`get_funding_rate_as_of_t` was re-reading the derivatives store (rglob +
`empty_frame`) for **every graded trade**; it now caches per
`(symbol, 8h bucket)`. The funding series is static during a backtest and
only changes on the 8h cadence, so the cached value is the identical row.
Turns 1,386 store reads into ~16 on the sample walk.

### `data/backtester.py` + `data/simulator.py` — the walk

`ind = add_all_indicators(df)` once, then `analyze_frame_at(ind, df, i, ...)`
per step. `run_backtest_on_store` inherits the win (it calls `run_backtest`).

## Honest boundaries

- "Incremental" here is **windowed recompute** (O(200) per step), not a
  true incremental slide: each step re-runs the detectors on the 200-bar
  tail. That is what makes behaviour-identical provable. A true sliding-window
  incremental detector is a possible later refinement, not needed for the
  target ≥3–10×.
- The remaining per-step floor is the grader itself (`_evaluate` + cost
  model), which is identical work in both walks and now the dominant cost —
  a natural target if backtests need to go faster still.
- The `verify_p134.py` harness and `structure_orig_snapshot.py` comparison
  module live outside the repo (review workspace) and are not shipped.
