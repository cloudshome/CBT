One command, one block. Long/short split, per-regime, per-session,

```bash

```

Also on the dashboard (STRATEGY SCORECARD card, `/api/scorecard`) and as

### P12.3.1 — the bug the scorecard exposed

Building the scorecard meant reading `_evaluate()` closely, and a bar that
touches **both** the stop and TP1 was being scored as a **win**:

```python
if first_sl is not None and (first_tp1 is None or first_sl < first_tp1):
```

The paper trader scores that same bar as a **loss**. Two graders
disagreeing, with the optimistic one behind every published number. Now
`<=`, so both engines call it a loss — the honest reading when intrabar
sequence is unknown.

## 2. The four findings that reordered the roadmap

The audit is the real deliverable of this session. In short:

1. **No real market data has ever entered this project.** 0 parquet files,
   0 paper rows. Every figure — P11's +0.263R, P12.3's +0.341R, every
   split — comes from `make_ohlcv()`, a seeded Gaussian random walk with
   no autocorrelation, no fat tails, no regime persistence, no stop-hunt
   structure. Those are the only things a technical edge can feed on.
2. **Costs are in nothing.** `EXECUTION_MODEL="none"`. Median stop distance
   0.823% of entry → 0.121R per taker round trip → **+0.341R gross ≈
   +0.22R net**. And at the 1.8h median hold, **fees ≈ 40× funding**,
   which inverts P12.6's original emphasis.
3. **Sample counts are inflated ~30×.** `step=3` against a 96-bar horizon
   overlaps ~32 neighbours: "384 decided" ≈ **12 independent**.
4. **Seed sensitivity straddles the bar.** +0.387R … +0.730R on identical
   settings. The headline number is noise.

Corroborating the first point: the tie-break fix changed **nothing** on
synthetic data — 0 ties across 3,263 decided trades over 5 seeds. Random
walks don't span a 1R stop and 2R target in one bar. Real wicks do,
routinely.

**So expectancy should fall when real data lands. That fall is the
correction arriving, not a regression.** Please don't let a future session
read it as one.
