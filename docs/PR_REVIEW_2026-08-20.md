## #72 — v2.49.0 The Trade Terminal (deep review)

**Claim:** SKY is now one professional trading platform. Default page
is watchlist + chart + paper ticket + AI + bottom tabs + six-area nav.
Presentation layer only. Suite 1282/1. Wheel gate green.

**What is true**

- The default view *is* a 3-column terminal. Six-area nav with SVG
  icons is real. Legacy panels are grouped, not deleted.
- The ticket is marked PAPER. Confirm stays disabled when the last
  scan payload says blocked. Mutations still go through existing
  endpoints. No new order path.
- `config.VERSION`, `pyproject.toml`, and `sky-shell-v2.49.0` are in
  lockstep (the invariant #71 just added).
- Handover correctly says: no browser, visual QA is next, Confirm is
  not the full desk path.

**What is not true, or not finished**

1. **Confirm Paper Trade does not create a paper trade.**
   `submitPaperTicket()` POSTs `/api/position-size`, then toasts
   “review the approval queue”. There is no `/api/review`, no scan
   enrollment, no position under the chart. Shipping copy that says
   “create a paper trade” oversells T1. This is **T3**.

2. **The rewritten `ROADMAP.md` was internally false on arrival.**
   Header said *Current software: v2.48.1*. Section 11 marked *Phase
   T1 — NEXT* after T1 had shipped. Typos: Gren/red, Toltips, Loding,
   Oen, Pnding, Aerts, Bckground, Contet, Cloe, colection, Plnned.
   Border colour `#1e3358` does not match shipped CSS `#1e2533`.
   Background `#070b14` is the theme-color; page `--bg` is `#0b0e14`.

3. **The rewrite dropped the core aim.** The previous merged roadmap
   carried P11 paper proof, the NET graduation bar, P12.12 XAU
   evidence, P22 signer drills, and “packaging never unlocks trading”.
   #72 replaced that with T1–T6 only. A terminal that cannot prove an
   edge is not the project.

4. **No new terminal tests.** Suite stayed 1282/1. Watchlist, ticket,
   Confirm, bottom tabs, and Copilot have no jsdom coverage. A
   presentation-layer change of this size should have pinned at least:
   Confirm does not call a mutation that bypasses the gate; ticket
   stays disabled when blocked; nav grouping does not drop Command
   Center.

5. **Bottom tabs cache forever.** `_bottomLoaded[tab]=true` after the
   first paint. Positions opened after that paint will not appear
   until a full reload. T4 item, but it makes T3 look broken if
   ignored.

6. **`loadTerminal()` runs once.** `_termLoaded` never clears. Leaving

7. **Selecting a position does not paint the chart.** It toasts and
   `navTo('portfolio')`. Fine as a scaffold; not the layout diagram.

8. **Ticket math is decorative.** Fees are `entry * 0.001` (notional

   has no balance. Size must eventually call `web/position_sizer.py`

9. **Watchlist is not a live ticker.** It maps `/api/agents` assets.
   Honest as “desk snapshot”; dishonest as “live prices” in the PR
   body.

10. **AI section parser still double-prints.** When it thinks it found
    sections it still appends the full answer (`filter(… || true)`).
    T2 remainder. Harmless, ugly.

11. **Splice process is fragile.** `web/app.py` HTML is still one

## #71 — v2.48.1 PWA cache lockstep

v2.48.0 shipped with `sky-shell-v2.47.0`. Installed PWAs would not
retire the previous precache. Two `sky-agent` tests called ambient
`python`, so a valid `.venv` pytest run could fail as “missing deps”.

Fix is exact and tested: three-way lockstep
(`config.VERSION` = `pyproject.toml` = `sw.js` cache suffix), proven
red before green; subprocesses use `sys.executable` + absolute
`main.py`. Privacy boundary unchanged (`/api/*` never cached).

**Keep forever.** A future T-step that bumps the app version and
forgets `sw.js` must fail CI.

Honest caveat in the PR: no browser DevTools lifecycle was observed.

## Cross-cutting findings (do not regress)

1. **Served-script trap.** `web/app.py` `HTML` is a non-raw Python
   string. `\\n` inside JS becomes a real newline and blanks the whole
   page. Tests must parse the *evaluated* template
   (`test_served_script_is_valid_javascript`). Keep it.
2. **Version lockstep.** `config.py` / `pyproject.toml` / `sw.js`
   cache id. #71 made this CI. #72 obeyed it. Keep it.
3. **No browser in sandbox.** Every UI PR in this window verified
   through jsdom + Flask + `node --check`. Say that. Do not imply a
   human saw the pixels.
4. **GitHub App cannot write `.github/workflows/`.** Active `ci.yml`
   Node-20 deprecation remains a repo-admin action
   (`docs/HUMAN_ACTIONS.md`).
5. **Presentation ≠ permission.** T1 did not (and must not) move the
   gate. Confirm must keep using the existing approval path in T3.
6. **Doc drift is a safety issue here.** When `ROADMAP.md` and
   `SESSION_STATE.md` disagree about the next step, the next agent
   will build the wrong thing. #72 demonstrated that.
