# W3.6 — Replay-integrated tape practice

**Shipped:** 2026-08-19 · v2.46.0 · branch `arena/01a01965-sky`

## Decision

W3.5's next sandbox job #2: replay-integrated practice with an explicit
forward-window outcome contract, kept separate from the live book until
the contract is proven.

## Delivered (clickable, not a roadmap)

On the Chart tab: start **Replay**, **Freeze** at the bar you are
reading, write your bias / call / optional ladder, click **Grade against
the tape**. The server fetches the same candle series the chart draws,
walks the bars *after* `commit_time` (default `horizon_bars=16`, clamp
4–64, need ≥4 hidden bars), and scores the outcome.

Outcome contract (`brain/practice.walk_tape`):

* **no-trade** → ATR-normalised close-to-close move (standing aside).
* **buy/sell, no ladder** → signed ATR move of the close.
* **buy/sell + ladder** → `data.paper_trading.exit_event` (same
  conservative stop-first rule the live paper runner uses).

Stored as `score.kind == "tape"` in the existing `practice_attempts`
table. `practice_scorecard` desk keys (`n`, `bias_agreement`, …) stay
desk-only. Tape lives under the sibling `tape` block. CLI
`python main.py practice`, `GET /api/practice`, the Review-tab card and
MCP `practice_scorecard` share that one computation.

Surfaces:

* Chart: `#replayFreezeBtn`, `#pracTapeBanner`, `#pracTapeBtn`,
  `submitTapePractice()` → `POST /api/practice/tape`.
* Review: sibling **TAPE — replay outcomes** card.
* Fail-closed: missing commit, unknown vocab, partial ladder, wrong-side
  levels, short forward window.

No threshold moved. No order path. Practice/tape never write
`paper_trades`, scans, graduation or the risk gate.
