## What this is

The client contract a WebView2 / Start-menu app must speak to the Ubuntu
Hub. The Hub remains the only DB, risk gate, and paper runner.

## Delivered here

- One-time pairing codes (`pairing_codes` table) — 8 chars, 10-minute
  TTL, hashed, single use.
- `POST /api/v1/pair` (public redeem) and `POST /api/v1/pair/code`
  (operator mint + QR JSON).
- `python main.py hub pair` and `python main.py companion spec|status|validate-url`.
- `ops/windows_companion.py` — HTTPS URL rules, compatibility check,
  Credential Manager / refuse-world-readable file store, tray snapshot,
  idempotent headers.
- Unsigned recipe: `packaging/windows/README.md`.

## Honest limits

- No signed `.exe`/MSIX, no Windows 11 install drill, no WebView2 binary.
- File-token fallback is test-only (`SKY_COMPANION_ALLOW_FILE_TOKEN=1`).
- No threshold moved. No order path.

## Safety

A companion cannot invent a Trade button: `/api/v1/version` still
advertises `live_exchange_execution: false`, and the client refuses a
Hub that claims otherwise.
