# W3.5 — Multi-chart comparison views

**Shipped:** 2026-08-19 · v2.43.0

## Delivered

The Chart tab now has an optional **▦ Multi-chart** view. It renders up to four
independent Lightweight Charts tiles:

1. the selected symbol and timeframe;
2. the selected symbol on a nearby timeframe;
3. BTCUSDT 1h;
4. ETHUSDT 1h.

Duplicate symbol/timeframe pairs are removed. Each tile requests its own
`/api/chart` payload and renders its own candles. Zooming or panning one tile
synchronizes the visible logical range across the other tiles, while prices,
indicators, plans and desk decisions remain independent. The 2×2 grid becomes
a single column on narrow screens.

The default remains the existing single chart. The multi-chart view is clearly
labelled **comparison only** and does not combine signals, alter the desk,
practice scoring, live streaming, replay, risk gate, paper book, or graduation.
The four slots can be changed with strict symbol/timeframe allow-lists and are
saved only in browser `localStorage` (`sky.multiChartSlots`); no private server
state is cached.
No order path was added and no threshold moved.
