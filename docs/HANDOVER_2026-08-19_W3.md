## What this is

HANDOVER.md carried two workstation priorities that survived every later
roadmap checkpoint (ROADMAP.md §3 "W3 Trader development"):

- **Priority 2 — the weekly trader review as a page**, not a `<pre>` dump:
  equity curve, R-multiple distribution, violations, expectancy, drawdown and
  the next practice task, with an export.
- **Priority 3 — the daily ritual with memory**, the per-setup graduation
  tracker, and **enforced journalling**: block the next approval while a
  closed trade is unjournaled.

This build ships all of them. The *only* Priority-3 item deliberately **not**
built is the practice-scoring mode (§"Not built").

## Delivered

### W3.1 — `brain/weekly.py` (one computation, many surfaces)

`weekly_review(db, days=7)` over the canonical live book only
(`live_book_rows` — P12.15), every judgement NET of costs (P12.18):

- week vs all-time stats (n / wins / losses / expectancy net + gross / PF /
  totals / avg win-loss / best-worst);
- equity curve **reused from `business_metrics`** — the Review tab cannot
  disagree with the Risk center (invariant #10);
- net-R distribution in 9 buckets (all-time + week variants);
- violations with the repeating-mistake and emotion breakdowns from the
  journal form, missing-journal scan ids, compliance vs the 90% bar;
- per-setup **graduation tracker** naming the exact missing evidence
  ("37 more unique backtest samples (63/100)", "E_net −0.03R < +0.50R bar");
- one deterministic `next_practice_task` picked by weakest link in desk
  order: journals → discipline → samples → expectancy → maintain;
- an advisory grade (A–E, components visible, note says it is **not** the
  graduation bar).

Surfaces sharing that one payload:

| Surface | Entry |
|---|---|
| CLI | `python main.py weekly [--days N] [--json] [--export PATH]` |
| HTTP | `GET /api/weekly` · `GET /api/weekly/export` (JSON attachment) |
| Dashboard | **🗓 Review tab** — stats, grade pill, task card, ritual card, equity chart, R-dist bars, discipline card, tracker rows, export button |
| MCP | root `weekly_review` (server 1.12.0) · SDK `cryptobrain_weekly` |
| Agent | `WeeklyReviewAgent` archives `payload["weekly"]` into `agent_runs` (summary line unchanged) |
| Command Center | "Weekly trader review" card |

### W3.2 — the daily ritual that remembers (`brain/ritual.py`)

- `ritual_checks(day, name, done, ts)` table; `PRIMARY KEY(day, name)`.
- The four steps are the same payload `loop_health()["ritual"]` publishes —
  we persist ticks, never duplicate the list. `GET /api/ritual` merges the two.
- `POST /api/ritual` ticks/unticks one canonical step; unknown names → 400
  (no invented ritual history); audited; operator role inherited from the
  P18.1 gate (fail-closed default for undeclared mutations).
- A new UTC day has no rows: yesterday's discipline cannot pretend to be
  today's. Ticks are a memory note, never permission — the risk gate and the
  graduation bar never read them.

### W3.3 — journal-first approval gate

`approve` (CLI + `POST /api/review`) now holds while
`brain.weekly.missing_journals()` is non-empty — decided, non-simulator,
canonical-live closes without a `followed_rules` answer (exactly the P12.14
fail-closed population):

- 409 with `journal_block{missing, scan_ids, trades}` + `acknowledge_available`;
- the dashboard shows the unjournaled trades; Cancel jumps to the Journal tab,
  OK resubmits with `acknowledge_journal: true` (audited in the decisions row);
- CLI exit 2 naming every missing scan; `--acknowledge-journal` is the escape;
- rejects/closes/skips are never held; simulator and research debt never
  holds; `--force` overrides the **risk gate** only, not journal discipline.

Direction: strictly tighter on the human. Nothing opened. The risk gate and
every threshold are untouched.

## Honest limits (verified vs. claimed)

- No real browser exists in this sandbox: UI verified via the node/jsdom
  harness (`tests/test_weekly_js.py`, 5 tests), the Flask test client, and
  curl against a running dev server. The equity chart look was not eyeballed.
- The `weekly_review` **agent** summary line is untouched (tests pinned); its
  archived payload grew.
- The practice task is coaching text — it blocks nothing by itself.
- The equity curve uses `closed_ts` seconds; same-second closes are deduped
  to a strictly increasing series for the chart.
- The grade is deliberately cheap arithmetic, not a model — it must never be
  cited as evidence of profitability.
