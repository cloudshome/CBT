## 0. One-paragraph summary

The desk is now installable from Chrome/Edge (desktop + Android) and safe when offline. A project-owned `manifest.json` + `Service Worker` precaches only the **shell** (HTML shell, chart lib, icons, offline page) and **never** caches private API payloads, auth, ` /api/chart/stream` or ` /api/v1/jobs/*/events`. A sticky offline banner and a disabled-mutations guard tell the truth when the network is gone; an explicit `offline.html` shell is always available. A beforeinstallprompt banner offers Add to Home Screen (with 7-day dismissal). The layout adds a `640px` compact mode so daily ritual, risk, paper positions, approvals and journal completion fit on a phone. No threshold moved, no order path exists.

## 2. What was built

### 2.1 `web/static/manifest.json` + icons

- `name: SKY · CryptoBrain Trading Desk`, `short_name: SKY`, `start_url: /?source=pwa`, `scope: /`, `display: standalone`, `background_color/theme_color #070b14`, `categories finance/productivity`.
- Icons `192, 512 (any) + 512 maskable + 180 apple` as project-owned PNGs under `web/static/icons/` (generated without Pillow via stdlib `zlib/struct`, 192≈547B, 512≈1.9KB). No external CDN.
- Shortcuts: Daily Ritual, Chart, Risk Center. Manifest served at `/static/manifest.json` and `/manifest.json` (public, before auth).

### 2.2 `web/static/sw.js` — safe-by-default worker

- `CACHE_NAME = sky-shell-v2.34.0`, `SHELL_URLS = [/, /offline.html, /static/manifest.json, /static/lightweight-charts.standalone.js, icons]`. Install precaches shell only, then `skipWaiting()`. Activate deletes old caches, `clients.claim()`.
- **Never-cache fence:** `if (req.method !== 'GET' || path.startsWith('/api/') || path==/sw.js||/manifest.json||/offline.html || path==/api/chart/stream || path.startsWith('/api/v1/jobs/')) return;` — bare `return` (no `respondWith`) so browser does network-only and CacheStorage never sees private JSON, auth cookies or SSE.
- Navigation `mode==='navigate'` → network-first, fallback to `/offline.html` (never cache HTML that may contain private state server-rendered).
- `/static/*` → stale-while-revalidate (fast render, background refresh, only `type==='basic'` + `ok` cached).
- Default → network-first `fetch().catch(()=>caches.match(req))`.
- `push` + `notificationclick` stub (Telegram/Discord remain primary; VAPID server is P19, the worker just shows the abstraction is wired). `message SKIP_WAITING` handler.

Headers: Flask serves `/sw.js` with `Service-Worker-Allowed: /` and `Cache-Control: no-cache, no-store, must-revalidate` so updates propagate.

### 2.3 `web/static/offline.html`

Always-available shell (precached). States: *You are offline — cached shell only, no fresh signal/risk/paper; Mutations disabled — approvals/rejections/paper runs/journal writes stay disabled until you reconnect; API/auth/SSE are never cached — network-only by design.* Shows `localStorage sky:lastUpdated`, connection, service worker state, and actions `Reload live desk / Check for update / Back`. Styled to match desk (no new dependency).

### 2.4 `web/app.py` — PWA wiring

- **Head:** `<link rel="manifest" href="/static/manifest.json">`, `<meta name="theme-color" #070b14>`, `apple-mobile-web-app-*`, `<link rel="apple-touch-icon" 180>` + icons.
- **Banners (sticky, above topbar):** `#offlineBanner` (⚠️ Offline — showing cached shell. Data may be stale. Mutations disabled. [Open offline page] · last good scan) with `show` toggle; `#installBanner` (📲 Install SKY — Add to home screen…) with `Install / Not now`. Both `display:none` by default.
- **CSS:** `#offlineBanner/#installBanner` styles + `body.offline .mutation` dim + `@media(max-width:640px)` compact (topbar, tabbar, shell, grid→1fr, formgrid→1fr, quickbar, statrow, etc.) and `@media(max-width:380px)` tiny.
- **Routes (public before auth):** `GET /sw.js`, `GET /manifest.json`, `GET /offline.html`, `GET /offline` — all exempt from `_auth_gate()` (which already exempted `/` and `/static/*`).
- **JS (before `</script>`):** IIFE that
  - tracks `online/offline` → toggles banner + `body.offline` + disables mutation buttons (`button[onclick*=decide|runPaper|saveJournal|clearTraderState]`) + updates `offlineWhen` from `localStorage`.
  - persists `sky:lastUpdated` on every `load()`.
  - `beforeinstallprompt` → `preventDefault()`, store `deferredPrompt`, show banner unless dismissed within 7 days; `installBtn` → `prompt()`; `appinstalled` → hide banner + toast; `dismissInstall()` → 7-day snooze.
  - `serviceWorker.register('/sw.js', {scope:'/'})` on `load`, `updatefound` → toast *SKY updated — reload*, `controllerchange` → reload once.
  - `window.SKY_push` stub + `window.SKY_compact()` helper for tests.
  - No backslash escapes inside JS string literals (uses `nl` variable or avoids `\n`) so `HTML` plain-string parsing stays `node --check` clean.

## 4. Honest flags (per §0a)

- **No real device was used.** Installability was proven via manifest validity, `beforeinstallprompt` wiring, and Flask test-client 200s + correct MIME/headers; not by installing on a real Android phone or Chrome. A human should install on Chrome/Edge desktop + Android and verify the icon appears and the offline page works after Load → Offline in DevTools.
- **Push is a stub.** `sw.js` handles `push` → `showNotification` and `notificationclick` → `clients.openWindow`, and `window.SKY_push` exposes `supported/permission/request`. But there is **no VAPID key, no push server, no subscription storage, and no Telegram/Discord replacement** — those remain the supported notifiers (per roadmap). A future P19 module can add `/api/push/subscribe` without changing the worker.
- **Icons are solid-color placeholders.** Generated via stdlib PNG writer (no Pillow) as `17,28,51` squares (≈0.5–1.9KB). They satisfy Chrome's *has 192 & 512* heuristic and maskable purpose, but a designed icon (brain + chart) should replace them before a public release. The worker and manifest already point to the right paths, so swapping files is zero-code.
- **The worker is shell-only by design.** That means the first paint after a hard offline is the shell + offline page, not the last signal. The offline banner says so explicitly — it does *not* pretend the cached API data is fresh. Mutations are disabled while `navigator.onLine===false`; the human must reconnect and let `/api/readiness` return fresh before acting. This is stricter than many PWAs and intentionally so.
- **Scope trick.** The file lives at `/static/sw.js` on disk but is served at `/sw.js` with `Service-Worker-Allowed: /` so its scope is `/`. A bare `/static/sw.js` registration would only control `/static/*` and would not make the desk installable.

## 5. What is deliberately not here

- **No push server, no VAPID keys, no subscription DB** — the worker stub is not a notification system.
- **No client-side cache of `/api/*` payloads** — there is no `Cache: put` for JSON, auth or SSE. The offline shell is honest that data is stale.
- **No app-shell data hydration from IndexedDB** — the shell shows the offline page; the last signal is only the timestamp in `localStorage`, not the JSON.
- **No iOS-specific standalone detection beyond the meta tags** — `apple-touch-icon` + `apple-mobile-web-app-capable` are present, but standalone `navigator.standalone` handling is not added.
- **No versioned SW cache migration beyond `sky-shell-<version>`** — sufficient for foundation; P19 may add `runtime` cache for `/static/*` with explicit version.
- **No threshold moved, no order path.** The PWA is a delivery shell over existing behaviour; the risk gate, graduation bar, and paper loop are untouched.

## 7. Operator checklist (try it)

```bash
# 1. Run desk
DEMO_MODE=1 python main.py web --host 0.0.0.0 --port 8050
# 2. In Chrome: open http://localhost:8050 → DevTools → Application → Manifest (should show SKY, 4 icons, theme #070b14)
#    → Application → Service Workers (should show /sw.js scope /, status activated)
#    → Application → Storage → Clear site data, then Reload → sw should install, shell cached
# 3. DevTools → Network → Offline checkbox → Reload → you should see the offline page or the banner ⚠️ Offline — showing cached shell. Mutations disabled.
# 4. With network back: Chrome menu → Install SKY (or address bar install icon). On Android: Chrome → Add to Home Screen.
# 5. curl smoke
curl -s http://localhost:8050/manifest.json | python -m json.tool
curl -s -I http://localhost:8050/sw.js | grep -i "Service-Worker-Allowed\|Cache-Control"
curl -s http://localhost:8050/offline.html | grep -i "Mutations disabled"
```
