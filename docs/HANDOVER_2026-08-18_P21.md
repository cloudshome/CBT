**Shipped:** 2026-08-18 · v2.37.0 · branch `arena/01a01486-sky`

## What this is

The client contract a native Android shell must speak to the Ubuntu Hub over
`/api/v1` — the Android analogue of the P20 Windows contract. The Hub remains
the only DB, risk gate, and paper runner.

## Delivered here

- `ops/android_companion.py` — Android client contract:
  - **HTTPS-only** Hub URL rules (loopback HTTP for dev) plus a
    **configured-host allowlist** (`host_allowed`) so a hardened WebView never
    navigates an arbitrary URL.
  - **Keystore-backed token storage** (`KeystoreTokenStore`) described for the
    Android Keystore; the sandbox fallback refuses writes unless
    `SKY_ANDROID_ALLOW_FILE_TOKEN=1` *and* the file is 0600 (test-only).
  - **Biometric re-check policy** (`biometric_policy`, `requires_biometric`)
    — declares *when* a BiometricPrompt must precede an operator mutation
    (paper approval, journal write, revoke device, paper reject, risk
    override). Declarative here; the real prompt lives in the APK.
  - **Online-only mutations** (`connection_snapshot`) — a paper approval is
    never queued for replay offline; an offline/stale feed blocks writes.
  - **Push / deep-link contract** (`deep_link`, `deep_link_surface`,
    `DEEP_LINK_TYPES`) — `sky://record/<signal|risk|paper|journal|dashboard>[/<id>]`.
  - `negotiate_version`, `pair_with_hub`, `mutation_headers`, `read_headers`
    reuse the P20/pairing machinery with `client=sky-android`.
- **CLI** — `python main.py companion spec --platform android`,
  `companion validate-url --platform android`, `companion status
  --platform android`, and `python main.py hub pair --platform android`
  mints an Android pairing payload.
- **Packaging** — unsigned recipe `packaging/android/README.md` (signing is
  P22).
- **Tests** — `tests/test_android_companion.py` (16 tests) plus the shared
  P20 pairing tests still green.

## Honest limits

- No signed APK, no Android device/emulator install drill, no
  `BiometricPrompt`/push-payload hardware in this sandbox — the module
  *describes* the contract; the native shell is a recipe.
- Keystore file fallback is test-only (`SKY_ANDROID_ALLOW_FILE_TOKEN=1`).
- No threshold moved. No order path.

## Safety

A companion cannot invent a Trade button: `/api/v1/version` still advertises
`live_exchange_execution: false`, and the client refuses a Hub that claims
otherwise. Deep links resolve only to known record surfaces.
